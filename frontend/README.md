## 🚀 Setup

*Instructions depend on the final framework choice.*

### Option A: If React/Node
```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
```

### Option B: If Streamlit
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the application
streamlit run app.py
```
