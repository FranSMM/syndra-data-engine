02 / How it worksCómo funciona

A medallion pipeline: Bronze, Silver, Gold. Un pipeline medallion: Bronze, Silver, Gold.

Each stage has one job and one contract with the next. Failures are isolated, states are explicit, and no article reaches the API until it has passed validation and enrichment. Cada etapa tiene una única responsabilidad y un contrato con la siguiente. Los fallos están aislados, los estados son explícitos y ningún artículo llega a la API sin pasar validación y enriquecimiento.

Contract guaranteesGarantías del contrato

  • Egress DTOs are separate from internal ORM models, so refactors never change your schema.Los DTO de egreso están separados de los modelos ORM internos, así que un refactor nunca cambia tu esquema.
  • Versioned path (/api/v1). Breaking changes get a new version, not a new field type.Ruta versionada (/api/v1). Los cambios rompedores generan una versión nueva, no un tipo nuevo.
  • Hard limit ceiling of 100 signals per request, enforced by Pydantic.Techo estricto de limit a 100 señales por petición, forzado por Pydantic.
  • Continuous score, not three buckets. A mildly pessimistic neutral reads −0.0664.Score continuo, no tres cubos. Un neutral algo pesimista da −0,0664.

Sentiment encodingCodificación del sentimiento

negative neutral positive

Diverging blue↔red with a gray midpoint, never red/green, and the label always travels with the colour. Escala divergente azul↔rojo con punto medio gris, nunca rojo/verde, y la etiqueta siempre viaja con el color.

04 / Self-hostedAutoalojado

Your data never leaves your perimeter. Tus datos nunca salen de tu perímetro.

Syndra ships as Docker Compose and runs in your VPC or on-prem. Ingestion, inference and storage all execute on your hardware. There is no Syndra-operated cloud to trust, no vendor egress to audit, and no third-party model API in the path. Syndra se distribuye como Docker Compose y se ejecuta en tu VPC o en on-prem. La ingesta, la inferencia y el almacenamiento corren en tu hardware. No hay una nube operada por Syndra en la que confiar, ni egreso de proveedor que auditar, ni API de modelos de terceros en la ruta.

06 / FAQ

Questions engineers ask first.Lo que pregunta primero un ingeniero.

Is this a trading signal?¿Es una señal de trading?

No. Public news is priced in almost instantly, so we make no claim of alpha. Syndra is structured input for your own research and risk models, not a recommendation engine.No. Las noticias públicas se descuentan casi al instante, así que no reclamamos alfa. Syndra es input estructurado para tus propios modelos de research y riesgo, no un motor de recomendaciones.

Which models run, exactly?¿Qué modelos se ejecutan exactamente?

FinBERT for sentiment, on GPU via CUDA when available, in an isolated subprocess. all-MiniLM-L6-v2 for embeddings, pinned to CPU so it cannot contend for VRAM. Both are local weights.FinBERT para sentimiento, en GPU vía CUDA cuando está disponible, en un subproceso aislado. all-MiniLM-L6-v2 para embeddings, fijado a CPU para que no compita por VRAM. Ambos son pesos locales.

What hardware does it need?¿Qué hardware necesita?

It runs CPU-only. A CUDA GPU is optional and materially faster for enrichment batches; inference is chunked iteratively so batch size never dictates the memory ceiling.Funciona solo con CPU. Una GPU CUDA es opcional y acelera notablemente los lotes de enriquecimiento; la inferencia se trocea de forma iterativa para que el tamaño de lote no dicte el techo de memoria.

How is the score computed?¿Cómo se calcula el score?

Net impact: P(positive) − P(negative) over the full class distribution, so a nominally neutral article still carries its directional bias instead of collapsing to zero.Impacto neto: P(positivo) − P(negativo) sobre toda la distribución de clases, de modo que un artículo nominalmente neutral conserva su sesgo direccional en lugar de colapsar a cero.

How do I authenticate?¿Cómo me autentico?

A static API key in the X-API-Key header, issued per deployment. Since the instance is yours, key rotation and rate limits are yours to set too.Una API key estática en la cabecera X-API-Key, emitida por despliegue. Como la instancia es tuya, la rotación de claves y los límites de tasa también los defines tú.
